# Sales & Revenue Analysis for a Small Business

Week 2 Case Study 2 implementation using Python/Jupyter, MySQL and Power BI.

## Repository contents
- `Sales_Revenue_Analysis.ipynb` - Python ETL, validation, analysis, forecasting and CLV.
- `SQL_Queries.sql` - MySQL staging validation and analytical queries.
- `DAX_Measures.dax` - Power BI measures and the customer display column.

## Dataset
- Sales: 2,705 transactions
- Customers: 1,000 customers
- Reporting period: January 1, 2024 to April 14, 2024

The repository contains the analysis code, not the source CSV files.
